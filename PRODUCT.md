## Platform
web

## Users and purpose
Владелец переключает основной сайт между Columbia и KRYGA через `/admin`.
Подтверждено пользователем: выбор общий для всех посетителей, а не локальный выбор браузера.
Посетители смотрят термобельё и оставляют заявку; доступны украинская и русская версии.

## Stack and constraints
Два существующих React + Vite проекта. KRYGA находится в корне, Columbia — в `columbia-site`.
Сохранить их страницы, оформление, языки, подбор размера и отдельные настройки заявок.
Существующие варианты размещения: Apache + PHP и Vercel. Целевой хостинг пользователь не уточнял.
Изменение действует при следующем открытии или обновлении страницы, не прерывая заполненную форму.
